# Page Visual OCR

Transcribe every requested page by looking directly at the original image with built-in visual recognition. Produce one UTF-8 HTML document with a separate section for each page, matching the clean page-by-page style of a manually verified visual transcription.

## Mandatory rules

- Read every page visually. Do not use Tesseract, EasyOCR, OCR APIs, PDF text extraction, browser OCR, or any other external recognition program.
- Do not reuse text generated by an earlier OCR engine, even if it is available locally.
- Do not replace missing transcription with the page image. The deliverable must contain text.
- Keep page order and page numbers. Never silently skip a page.
- Preserve Hebrew as real Unicode in logical reading order and use `lang="he" dir="rtl"`.
- Isolate mixed-direction content such as `(x, y)`, equations, Latin letters, URLs, and coordinate pairs with direction-aware spans.
- Preserve headings, paragraphs, lists, tables, labels, and meaningful diagram information. Describe diagrams in text when exact reproduction is not practical.
- Attempt every passage to the best of your visual-reading ability; do not use `[unclear]` as a shortcut or to avoid completing a page.
- If a tiny fragment remains genuinely illegible after a full attempt, transcribe the surrounding content and mark only that fragment `[illegible]`.
- Continue through the final requested page even when earlier passages are difficult. If the workflow fails or stops, report that plainly instead of presenting a partial result as complete.

## Required workflow

1. Locate the highest-resolution source image for each requested page.
2. Inspect and transcribe pages sequentially, keeping each page in its own HTML section.
3. Preserve visible structure: headings, paragraphs, lists, tables, captions, labels, exercises, and diagram descriptions.
4. Use logical Unicode order. Wrap Latin and mathematical fragments in direction-isolated spans so coordinate pairs remain readable.
5. Make a best-effort transcription of every visible passage. Mark only genuinely illegible fragments as `[illegible]`, and never use placeholders for an entire page.
6. Generate one standalone HTML file using UTF-8, `lang="he"`, `dir="rtl"`, readable typography, and clear page separators.
7. Report any `[illegible]` fragments and any actual workflow failure in the final handoff.

## Output template

Use a structure like:

```html
<section class="page" id="page-7">
  <h2>Page 7</h2>
  <p>Transcribed text goes here.</p>
</section>
```

Use CSS for readable line spacing and page separation. Do not embed source images as a substitute for transcription.
